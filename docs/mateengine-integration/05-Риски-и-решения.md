# Риски и решения

| Риск | Вероятность | Влияние | Решение |
|---|---:|---:|---|
| Chat path падает при InputField/caret | высокая | высокое | сначала отдельный regression test; null-safe и lifecycle guards; не считать bridge причиной без stack trace |
| Headless backend отсутствует | доказано | критическое | Phase 0: выделить Qt-independent service из InterfaceSignals; не запускать QApplication в backend |
| Linux sleep manager вызывает Windows-only idle function | высокая | высокое | отключить desktop heartbeat в MVP; добавить Linux adapter или explicit unavailable state в P1 |
| Linux capability mismatch/ложный success | высокая | высокое | tools/MCP/STT/OS actions отключить в MVP; capability matrix и explicit unsupported в P1 |
| Approval gate зависит от Qt banner | доказано | критическое | default-deny; approval.request protocol только в P1 |
| MCP fallback обходит approval | доказано | критическое | MCP disabled в MVP; единый policy gate/allowlist/audit в P1 |
| Unity и SoW используют разные event loops | высокая | высокое | async adapter, bounded queues, main-thread dispatch |
| Дубликат bubble: SoW + ChatBot + random path | высокая | среднее | отключить Unity LLM/random paths в MVP; correlation/request IDs |
| Reconnect создаёт повторную реплику | средняя | высокое | event_id dedupe + state snapshot |
| История и memory фиксируются в разных async контурах | высокая | высокое | single-writer canonical commit и sequence IDs |
| API key попадёт в Unity scene/log | средняя | критическое | key только на SoW; secret audit; sanitized errors |
| Linux X11/Wayland window regression | средняя | высокое | не смешивать app IPC с ShojiBridge; staged copy; rollback |
| TTS latency/format mismatch | средняя | среднее | TTS/audio только P1, сначала SoW-side playback + lifecycle events |
| Active Assembly-CSharp provenance не совпадает с default build | доказано | высокое | зафиксировать provenance/hash; не применять default build patch к active player |
| MateEngine license/assets restrictions | высокая | критическое | публиковать source changes открыто; не коммитить личные модели, player, Steam assets, keys; сохранить notices |
| SoW GPL + MateEngine proprietary-style license | высокая | критическое | не копировать исходники между проектами; protocol boundary; до публикации проверить совместимость лицензий юристом/maintainer |

## Лицензионная граница

Рабочий вариант для репозитория SoW — хранить только protocol specification, tests и независимый adapter code, если он не содержит MateEngine source и не подтягивает proprietary assets. Изменения Unity/C# держать в соответствующем MateEngine fork или отдельном открытом companion repo с полными notices.

В опубликованных MateEngine notices обнаружены противоречия между запретом binary/commercial distribution и специальным разрешением Steam Workshop, а также Qwen/Llama notice mismatch. Это требует письменного толкования правообладателя и отдельного inventory перед публикацией; текущая оценка не является юридическим заключением.

Не коммитить:
- personal VRM/model/texture/audio;
- `MateEngineX.x86_64` и player Data;
- Steam libraries/DLC/Workshop bundles;
- `api.json`, `.env`, tokens, logs with prompts;
- пользовательские profile/persistentDataPath files.

## Условия отката

До каждого staged player change:
1. копия launcher/player;
2. SHA-256 inventory;
3. отдельный log/evidence directory;
4. восстановление старого launcher path и restart только agent-owned unit.
